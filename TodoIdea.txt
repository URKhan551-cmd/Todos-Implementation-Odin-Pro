Which functions belong to storage?
Your storage functions are in the wrong place
You wrote:
function for getting data object into localStorage and
function for retrieving data from localStorage
These should not belong to Todo.
They belong to:
storage.js

Todo module
     ↓
creates/modifies Todo

Storage module
     ↓

Storage module
Your storage design is mostly correct.

Storage
│
├── save()
├── load()

But here's an important points
Don't make storage responsible for:
deleteTodo()
Storage doesn't know what a Todo is supposed to do.
Instead:


==>>   function for local storage keeping the things from function to local storage
       function through ID retrieve data from local Storage.
       function to delete todo from storage.
